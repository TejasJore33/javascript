4	React Basics	What is JSX?
How is React different from vanilla JS?
5	Components	Functional vs Class components?
How does React update the DOM?
6	State & Props	How does state lifting work?

What are dynamic and nested routes?
12	Context API	When would you use Context API over props?

13	State Management	Redux vs Context vs Zustand?

14	Debugging	How would you debug a performance issue in a React app?
